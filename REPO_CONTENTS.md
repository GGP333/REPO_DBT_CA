# Repo_DBT_CA — Contents & Provenance

Support repository for the manuscript *3D Segmentation of DBT Volumes (Digital Breast
Tomosynthesis)* (BMC v10). It contains the **code, configurations, evaluation metrics and
result figures** needed to inspect and reproduce the reported experiments. Large binary
artifacts (raw/preprocessed imaging data, model weights, voxel-level prediction arrays) are
**intentionally excluded** — they are reproducible from the code and are too large / contain
patient-derived data unsuitable for distribution.

## What is included

| Path | Contents |
|------|----------|
| `README.md` | Full project description (architectures, datasets, training, metrics, results). |
| `requirements.txt` | Python dependencies. |
| `src/` | All source code: preprocessing, the 2 in-house architectures (`unet_bce`, `attention_unet`), shared utilities, evaluation, and `plot_training_curves.py` (training-loss figures). |
| `experiments/nnunet_official/scripts/` | Official nnU-Netv2 pipeline scripts and custom trainers (`nnUNetTrainer_Seeded42`, etc.), plus `metrics.py` (shared metric implementation). |
| `experiments/nnunet_official/eval/*.json` | Official nnU-Net test results per dataset. |
| `experiments/nnunet_official/nnunet_root/` | Lightweight nnU-Net configs: `dataset.json`, plans, `splits_final.json`, fingerprints, `summary.json` (validation_best / validation_final) and the `training_log_*.txt` (per-epoch loss). |
| `results/outputs_clean/` | **UNet_BCE re-trained without data leakage** for Large / Small / Mixed_Size (metrics, curves, sample figures, run configs). |
| `results/outputs_improved/` | `Attention_UNet` across the 4 datasets, plus the clean `UNet_BCE_Dataset_Hybrid` run. Metrics, training curves, qualitative sample figures and run configs. |
| `results/figures/` | Per-dataset training-loss figures (`training_curves_<dataset>.png`), 3 panels each (3D U-Net / nnU-Net / Attention U-Net), generated by `src/plot_training_curves.py`. |
| `docs/data_leakage_audit.md` | Audit report documenting the UNet_BCE leakage and its resolution. |
| `_descartado/` | Material **not used in the manuscript**, kept for traceability only: the in-house nnU-Net replica (`nnUnet_original`) and its source code, the `Modelos_Arreglado_v2` duplicate bundle, and exploratory nnU-Netv2 trainers (`5epochs`, `PaperStandardized_3ep`, `ARCHIVED_BUGGY`). |

## What is excluded (and why)

- **`Dataset/`, `Dataset_Preprocessed/`, `data/`** — raw/preprocessed DBT volumes (~15 GB, patient-derived). Regenerate with `src/preprocessing/`.
- **Model weights** (`checkpoints/`, `*.pt`, `*.pth`) — reproducible by training.
- **Prediction arrays** (`preds_npy/`, `test_preds_npy/`, `*.npy`) — reproducible at inference; qualitative `samples/*.png` are kept instead.
- **`nnunet_root/{raw,preprocessed}`** large tensors and `eval/predictions/` NIfTIs.
- **`Experimento_Cristina_Alfaro_Enviar*`** and `*.zip` archives.

## Important caveat — UNet_BCE data leakage

The original UNet_BCE runs for **Large / Small / Mixed_Size** (in the project's `outputs_improved/`)
suffered 100% train↔test leakage and their test metrics were **invalid**. They are **not**
included here. Instead, `results/outputs_clean/` contains the leakage-free re-trained runs for
those three datasets. The `UNet_BCE_Dataset_Hybrid` run was already clean and is kept
as-is. See `docs/data_leakage_audit.md` for the full analysis.

## Architectures × datasets covered (manuscript)

The manuscript reports **three** architectures:

- **nnU-Net** → official **nnU-Netv2** (`experiments/nnunet_official/`, `nnUNetTrainer_Seeded42`).
- **3D U-Net (baseline)** → **UNet_BCE** (`results/outputs_clean/` for Large/Small/Mixed_Size,
  `results/outputs_improved/UNet_BCE_Dataset_Hybrid`).
- **Attention U-Net** → **Attention_UNet** (`results/outputs_improved/`).

The in-house nnU-Net replica (`nnUnet_original`) was **superseded by the official nnU-Netv2**
and is **not** part of the manuscript; it lives in `_descartado/`.

- Datasets: **D001 Large**, **D002 Small**, **D003 Mixed_Size** (synthetic/curated), **D004
  Hybrid** (test set = 100% real clinical cases → out-of-distribution evaluation).
